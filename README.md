<center>
Soundtrack areas for mapmakers.<br/>
Maintained for use at <a href="https://modfest.net">ModFest</a> events.<br/>
Requires <a href="https://modrinth.com/mod/area_lib">Area Lib</a>.<br/>

</center>

---

Usage:

- `/meret set` - set the music for an area to a specific sound. jukebox tag compatible.
- `/meret clear` - remove the music override for an area.

Config (`config/meret.toml`):

- `overrideAll` - prevent standard situational music from playing in-game (menu music will still play)
